# grok — تطبيق ذكي لأتمتة الفيديو بالذكاء الرقمي

تطبيق عصري بأحدث المعايير لإنشاء الفيديوهات على grok.com باستخدام Puppeteer وذكاء إعادة المحاولة وتسجيل الأعطال وتحليل النجاح، وتحكم ذكي كامل (قابل للتوسعة إلى واجهة رسومية وأتمتة سحابية)!

---

## المزايا الأساسية
- تخصيص كامل عبر config.json
- إدارة متقدمة للأخطاء: أعطال، إعادة المحاولة، سجل كامل، حفظ لقطات شاشة وHTML
- دعم تلقائي للإشعار بالبريد (اختياري)
- اختبارات أدوات utils جاهزة
- هيكلة تدعم التحويل مستقبلاً لـGUI، Webhooks، تعدد لغات

## التشغيل

1. قم بتعديل ملف `config.json` كيفما تريد.
2. أنشئ ملف `titre.txt` للعناوين (كل عنوان بسطر).
3. ضع ملفات نصية للمشاهد في مجلد `video_scripts`.
4. ثبّت الاعتمادات:
    ```
    npm install puppeteer-extra puppeteer-extra-plugin-stealth puppeteer nodemailer
    ```
5. شغّل الكود:
    ```
    node main.js
    ```
6. اختبر الأدوات:
    ```
    node utils.test.js
    ```

## الإشعار بالبريد (اختياري)
ضبط بيانات البريد كمتغيرات بيئية:
```
export NOTIFY_EMAIL_USER=your@gmail.com
export NOTIFY_EMAIL_PASS=xxxxxxx
export NOTIFY_EMAIL_TO=targetuser@gmail.com
```

## مزايا ذكية
- استئناف تلقائي لأي مشهد فشل بعد التنفيذ الكامل
- حفظ كل أخطاء التشغيل في مجلد `errors`
- تقارير مدة التنفيذ والنجاح
- توثيق وتطوير مستمر بأساليب حديثة
